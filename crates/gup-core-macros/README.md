# gup-core-macros

Part of [Gup](https://github.com/au-phiware/gup), GPU-accelerated charts for
Rust. Procedural macros for gup-core: `#[wgsl_function]` and `#[derive(Mark)]`.

Applications depend on [`gup`](https://crates.io/crates/gup); this crate is an
implementation detail of it. Licensed under GPL-3.0-or-later.
