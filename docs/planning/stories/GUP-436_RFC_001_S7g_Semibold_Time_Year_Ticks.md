# GUP-436: RFC-001 Step S7g: Semibold Year Ticks on Time Axes

## Story Overview

**Initiative**: RFC-001 Migration **Status**: 📋 Planned **Created**: 2026-10-16

## Context

RFC-001's "S5b findings → Proposed adjustments" asks for "Typographic hierarchy
for `Time` ticks: a year label (`2020`) should outweigh a month label (`Jul`).
That needs a second weight in the bundled font." `Time` labels each tick by the
coarsest calendar unit it begins (`scale/time.rs` lines 20–25, 323), so a
monthly axis already says `2021` at January, but every label is drawn in Inter
Regular: `gup-text` holds one face per `TextSystem`
(`crates/gup-text/src/system.rs` lines 184–220), its atlas is keyed by
`(char, size)` (`atlas.rs` line 52), and `Run` and gup-core's `TextStyle` have
no weight. Split out of [GUP-425](GUP-425_RFC_001_S7b_Theme_And_Axis_Titles.md)
on 2026-10-16.

The bundled face is a subset of Inter Regular 4.1 (`crates/gup-text/fonts/`,
regenerated by `mask subset-inter`, GUP-407). Its size counts against
`wasm.scatter.gz_bytes` (302,929 B, +2% tolerance) and `wasm.over_wgpu.gz_bytes`
(≤ 400,000 B) in `crates/gup-core/PERF_BUDGETS.md` lines 77–79.

## User Story

> "As a reader of a time-series chart, I want year labels to stand out from
> month labels, so that I can find years at a glance."

## Acceptance Criteria

### AC1: A second bundled weight

- [ ] `crates/gup-text/fonts/` holds `Inter-SemiBold.ttf` (Inter 4.1, from the
      same release as Regular) and `Inter-SemiBold-Subset.ttf` made by
      `mask subset-inter` with the same character list; the task subsets both
      faces and prints both sizes.
- [ ] `gup_text::INTER_SEMIBOLD` and `Font::inter_semibold()` exist; a test
      asserts the subset covers every character the Regular subset covers.

### AC2: Weights in gup-text

- [ ] `gup_text::Weight { Regular, SemiBold }` (default `Regular`); `Run` has
      `weight`; `TextSystem::measure_weight(text, size, weight)` exists and
      `measure` means Regular. A test measures "2021" at 12 px in both weights
      and the SemiBold width is larger.

### AC3: Year ticks render heavier

- [ ] `Ticks` has `major: Vec<bool>`, true for a `Time` tick that begins a year
      while the tick interval is shorter than a year, false elsewhere (every
      other scale: all false). Unit test on a monthly domain across 2020–2022:
      exactly the January ticks are major.
- [ ] Golden `gup_core/time_tick_hierarchy` (720×300, monthly ticks over two and
      a half years) read by eye: year labels visibly heavier than month labels.
      The retrospective describes the PNG.
- [ ] SVG output sets `font-weight="600"` on major labels and, with
      `embed_font`, embeds the SemiBold subset as a second `@font-face` (test on
      the SVG text).

### AC4: Size budget

- [ ] `mask wasm-size` runs; `wasm.over_wgpu.gz_bytes` stays ≤ 400,000 B. If the
      scatter harness grew by ≤ 40,000 B gz, re-record `wasm.scatter.gz_bytes`
      in `PERF_BUDGETS.md` with the reason "second Inter weight (GUP-436)"; if
      it grew more, stop (Escalation Triggers).

## Decisions

- **Font**: Inter 4.1 SemiBold (weight 600) from the official release
  (`https://github.com/rsms/inter/releases/tag/v4.1`), committed full and subset
  like Regular, under the same OFL file.
- **gup-text**: `TextSystem` keeps one lazily loaded face per weight
  (`[OnceLock<Font>; 2]`, SemiBold loaded on first use);
  `with_font(device, font)` uses `font` for both weights; new
  `with_fonts(device, regular: Font, semibold: Font)`. Atlas keys become
  `(char, u32, Weight)`. `ink_bounds(run)` and `layout(run, …)` use
  `run.weight`.
- **gup-core**: `TextStyle` gains `weight: gup_text::Weight` (re-exported as
  `gup_core::scene::Weight`); every construction site sets `Regular` except
  major tick labels, which `Plot::resolve` sets to `SemiBold`.
- **Major ticks**: `Time::ticks` sets
  `major[i] = interval < year && tick_begins_year(t)`. All other `Ticks`
  constructions use `vec![false; n]`.

## Escalation Triggers

- The Inter 4.1 SemiBold file cannot be downloaded in the worker's environment.
- `wasm.over_wgpu.gz_bytes` exceeds 400,000 B, or the scatter harness grows by
  more than 40,000 B gz.
- Any existing golden changes (only `time_tick_hierarchy` is new; existing
  `Time` goldens use yearly ticks, which have no majors).

## Out of Scope

- Bold chart titles or legend titles: not planned here (a one-line follow-up
  once weights exist).
- Font fallback, variable fonts: not planned.
